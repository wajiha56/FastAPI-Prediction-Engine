⚡ Setup Instructions

Clone Repository

git clone https://github.com/wajiha56/FastAPI-Prediction-Engine.git
cd FastAPI-Prediction-Engine

Install Dependencies

pip install fastapi uvicorn

Run Application

uvicorn api:app --reload

Open browser → http://127.0.0.1:8000 to test endpoints.

📌 Git & GitHub Workflow

Professional GitHub workflow demonstrated in this project:

Initialize Git:

git init

Add all files:

git add .

Commit changes:

git commit -m "My first API commit"

Add remote repository:

git remote add origin https://github.com/wajiha56/FastAPI-Prediction-Engine.git

Push code to GitHub:

git push -u origin main
